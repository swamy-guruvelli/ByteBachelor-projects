# Capacity estimation

The implementation milestone will state an average and peak workload before
selecting partitions, cache size, worker count, or storage retention.

Record:

| Input | Baseline | Measured value |
| --- | ---: | ---: |
| Average requests/events per second | 100 | pending |
| Peak-to-average ratio | 10× | pending |
| Average payload | 1 KiB | pending |
| Retention | 30 days | pending |
| Cache hit target, when applicable | 90% | pending |

The values are starting hypotheses, not portfolio claims. Replace them with
results from the load-test milestone.
